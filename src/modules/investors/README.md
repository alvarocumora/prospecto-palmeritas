# Investors Module

Owns investor CRM, interactions, pipeline tracking and future distribution workflows.

## Future ownership

- Investor profiles
- Investor interactions
- Deal distribution
- Campaign tracking
- Pipeline metrics

## Boundaries

- `domain/`: investor types, interaction types and scoring rules.
- `application/`: add interaction, qualify investor and attach investor to deal.
- `infra/`: Supabase/server-function adapters.
- `ui/`: CRM views, pipeline panels and campaign screens.
